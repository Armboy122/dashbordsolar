## งานรอบนี้
- ต่อจาก component และ stylesheet ที่แก้ค้างไว้ ไม่ reset หรือแทนที่งานทั้งชุด
- เชื่อม stylesheet ใหม่เข้ากับชื่อ component จริง: เดือน/ขอบเขต ความครบถ้วน KPI ปุ่มหลัก และ legend ซึ่งก่อนหน้านี้แสดงเป็นข้อความไม่จัดหน้า
- กราฟเต็มความกว้าง สลับเส้น/แท่งคู่ ปีที่ผ่านมาแยกสีและลาย อ่านผ่านปุ่มเดือนและตารางได้
- แก้ KPI กรณีไม่มีไซต์ร่วมสองปีไม่ให้ย้อนกลับไปเปรียบเทียบยอดรวมคนละกลุ่ม; ช่องว่างตัวเลขไม่กลายเป็นศูนย์
- มือถือการ์ดหนึ่งคอลัมน์ เมนูครบสี่หน้า ชื่อไทยตัดบรรทัดได้ ไม่มีการซ่อน overflow ของทั้งหน้า
- รายละเอียดแยกข้อเท็จจริง สาเหตุที่เป็นไปได้ วิธีตรวจต่อ ประวัติซ่อม และ AI
- ผล AI ระบุว่าอ้างอิงข้อมูล ณ เวลาวิเคราะห์ และล้างผลเดิมเมื่ออ่านประวัติไม่พบผล
- ปรับเอกสารเดือนทะเบียนจากข้อมูล refresh ที่มี artifact ยืนยันแล้ว ไม่ได้แก้ข้อมูล DB ในรอบนี้

## ข้อมูลจริง / จำลอง / ยังขาด
ข้อมูลรายเดือน กราฟ จำนวนไซต์ ประวัติซ่อม และประวัติ AI อ่าน API เดิม ไม่สร้างผลตรวจหรือสถานะ sync จำลอง
แนวทางสาเหตุทั่วไปและผล AI เป็นข้อเสนอ ไม่ใช่การยืนยันจากช่าง
จำลอง HTTP 503 เฉพาะ browser QA เพื่อทดสอบ error แล้วถอด interception ออก ไม่เปลี่ยน backend
ยังขาดระบบสถานะติดตามงาน สิทธิ์ผู้ใช้ export และหน้าประวัติ sync — แสดงเป็นรายการข้อความ ไม่ใช่ปุ่มหลอก
